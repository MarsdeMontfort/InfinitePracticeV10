# InfinitePracticeV10

Educational mnemonic generator with AI-powered video narration.

## Documentation

- **[Video Player API Documentation](./VIDEO_PLAYER_API.md)** - Comprehensive API reference for the video player component
- **[Video Player Quick Reference](./VIDEO_PLAYER_QUICK_REF.md)** - Quick start guide and developer reference

## Features

- Visual mnemonic scene generation
- AI-powered image creation (GPT-Image-1.5)
- Text-to-speech video narration (8 voice options)
- Interactive video player with playback controls
- Anki card export with cloze deletions
- Batch processing support

## Quick Start

1. Enter your OpenAI API key
2. Input medical concepts or mnemonic notes
3. Click "Generate All" to create scenes
4. Click "▶ Play Video" to view with narration
5. Export to Anki TSV or download images
